# The Prompt to copy and paste

Create a simple pizza restaurant website.

The website should have these pages:
1. Home page
2. Menu page
3. Extras page
4. Order page

##HOME PAGE:
- Add a welcome message saying “Welcome to SuperSlice Pizza!”*
- Add a large pizza photo*
- Add a short sentence about the restaurant*

##MENU PAGE:
- Add a list of pizzas with descriptions and prices:*
  - Margherita – tomato, mozzarella, basil – £7*
  - Pepperoni – tomato, mozzarella, pepperoni – £8*
  - Veggie – tomato, mozzarella, peppers, onions, sweetcorn – £8*
  - BBQ Chicken – BBQ sauce, chicken, onions – £9*

##EXTRAS PAGE:
- Add sides:
  - Garlic Bread – £3*
  - Fries – £2.50*
  - Cheesy Bites – £3.50*
- Add drinks:*
  - Coke – £1.50
  - Lemonade – £1.50
  - Water – £1
- Add desserts:
  - Brownie – £2.50
  - Ice Cream – £2

## ORDER PAGE:*
- Create an order form where customers can:
  - Choose a pizza from a dropdown list
  - Choose extras (tick boxes)
  - Enter their name
  - Enter their address
  - Enter their phone number
- After submitting, show a message saying “Thank you for your order!”

When the website is ready, show me a preview and then publish it.
